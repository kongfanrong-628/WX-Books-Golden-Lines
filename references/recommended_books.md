# 推荐补入书架的书单（填补金句库主题缺口）

> 用途：你的微信读书金句库目前集中在「个人成长 / 经济理财 / 心理 / 哲学宗教」，
> **缺「副业变现 / AI / 认知思维」三类**——而这恰恰是你最高频的选题。
> 把这些书加进微信读书书架后，重跑 `collect.py`，金句库的主题覆盖就补齐了，
> 写对应选题时第 3 条金句就不会再降级成弱匹配。

## 操作 SOP

1. 在微信读书里把上面想补的书**加入书架**（不用读完，热门划线照样抓得到）。
2. 回到 WorkBuddy，说一句「同步金句库」或跑：
   ```bash
   python scripts/collect.py
   ```
3. `collect.py` 按 `md5(文本)` 去重，**只追加新书/新划线**，旧的不动。
4. 之后写对应选题的口播稿，`insert.py` 就能从补齐后的库里挑出强匹配金句。

> 红队提醒：书单是我按「和你人设/选题重合度」初筛的，不是豆瓣神榜。
> 你可以先加 3-5 本试水，看哪类金句真被你用上，再决定要不要补齐剩余。
